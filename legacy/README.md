# Legacy Code

This folder contains archived code that is no longer part of the active
MJX-Warp / DeepMimic-style training path.

## Files

- `barkley_legacy_walking.py`: old Berkeley/MuJoCo Playground baseline runner.
- `walking_analysis.py`: old Berkeley-vs-biomechanics checkpoint analysis.
- `walking_analysis.ipynb`: notebook version of the old report workflow.

Keep these files for historical comparison only. New work should use the root
`train.py`, `evaluate.py`, `biomechanics_env.py`, and `bvh_reference.py`.
